사용자가 선택한 화면·포장 방식과 핵심 기능 3가지를 기록합니다. 이번 변경은 이 문서 추가뿐이며 앱 코드·설정·의존성·기존 제출물은 수정하지 않습니다. 이후 코드를 고치기 전에는 수정할 파일 목록과 이유를 먼저 제시하고 사용자의 확인을 받습니다.

- 기존 저장소: `https://github.com/DEV-JayWhy/choi-bujang-secret-vault`
- 기준 브랜치: `main`
- 기준 커밋: `5e4feee9f33b42c7dc6a86eae58815f97ecbe76f`
- 앱 위치: 기존 저장소의 `on-client`
- 현재 앱 package 버전: `0.2.11`
- 화면 틀: **관제 대시보드형** — 상단 상태 카드 네 개, 하단 추이와 최근 조회 기록

마지막 총공세는 기존 케셰브를 일상에서 쓸 수 있게 다듬는 작업입니다. 새 점수·진도나 실제 운영 인증을 얻었다고 기록하지 않습니다. 이전 커밋과 제출 기록은 보존합니다.

## 다듬을 핵심 기능 3가지

| 순서 | 핵심 기능 | 계획한 결과 | 확인 기준 |
|---|---|---|---|
| 1 | 내 PC 상태 카드 네 개 | CPU·메모리·디스크·방화벽 상태와 조회 시각 표시 | 앱 서버가 실행되는 PC에서 읽은 값만 실측으로 표시. 권한 부족·미지원·실패는 확인 불가 |
| 2 | 실측 추이와 최근 조회 기록 | 하단 CPU·메모리 추이와 시각별 조회 결과 | 실제 샘플만 추이에 사용. 조회 실패를 0·정상으로 채우지 않고 조회 시각·실패 원인을 구분 |
| 3 | 기본 포장과 바로가기 실행 | 향후 `npm run package-app`으로 실행 묶음·설치 안내·바로가기 준비 | 기존 프로젝트를 보존한 별도 출력물에서 시작·종료·재실행을 확인. 명령을 구현하기 전에는 사용 가능하다고 안내하지 않음 |

방화벽은 상태 조회만 대상으로 하며 설정 변경·차단·해제는 이 계획에 포함하지 않습니다. 현재 합의한 포장은 기본 포장이며 setup.exe는 이번 목표에 포함하지 않습니다.

## 실측값·예시값·확인 불가 표시 원칙

| 구분 | 화면에 표시할 내용 | 처리 원칙 |
|---|---|---|
| 실제 조회 | `실제 조회`, 측정 대상·출처·시각·단위 | 앱 서버가 실행되는 컴퓨터에서 얻은 값만 표시. AI 실행 환경의 값을 사용자 PC 값이라고 쓰지 않음 |
| 예시 | `예시 · 실제 조회 결과 아님` | 화면과 설명에서 계속 구분. 실제 기록·추이와 섞지 않음 |
| 확인 불가 | 확인 불가와 이유·조회 시각 | 권한·미지원·시간 초과·실패를 정상이나 0으로 바꾸지 않음 |

이 문서의 수치나 예제 설명은 사용자 PC 실측 증거가 아닙니다. 기존 `demo` 자료는 실제 계정·보안 기록으로 저장하거나 표현하지 않습니다.

## 현재 앱을 다시 실행하는 순서

사용자의 기존 프로젝트 안 `on-client` 폴더에서 PowerShell을 엽니다. 사용자의 Windows 절대 경로는 아직 확인하지 않았으므로 임의 경로를 실제 경로로 적지 않습니다.

```powershell
node --version
npm --version
npm run check
npm start
```

1. `케셰브 연결 확인: http://127.0.0.1:5189` 시작 메시지를 확인합니다. 이는 로컬 서버 시작이며 실제 엔진 연결 성공이 아닙니다.
2. 브라우저에서 `http://127.0.0.1:5189/`를 엽니다. 기본 미연결 상태를 정상 데이터로 오해하지 않습니다.
3. 예시 자료를 보려면 실행 창에서 `Ctrl+C`로 종료하고 같은 폴더에서 `npm run demo`를 실행합니다. 자료가 예시임을 확인합니다.
4. 기본 실행으로 돌아가려면 `Ctrl+C` 후 `npm start`로 다시 켭니다. 현재 앱 폴더는 외부 npm 의존성이 없어 기본 실행에 별도 의존성 설치가 필요하지 않습니다.

사용자가 지금 당장 직접 실행해야 다음 개발이 가능한 것은 아닙니다. 코드·검사·GitHub 반영은 AI 작업 환경에서 진행할 수 있습니다. 다만 사용자 PC 실측값, Windows 권한·방화벽 조회, 실제 브라우저 조작, 바로가기 실행은 마지막에 사용자 PC에서 별도로 확인해야 합니다. 그때 필요한 순서를 한 번에 하나씩 안내하고 실행하지 못한 항목은 미확인으로 남깁니다.
